# Positioning

> Status: Draft | Owner: Marketing | Last Updated: 2026-08-14

## Category

**Visual Infrastructure Platform** — not just IaC, not just a design tool, not just observability. A platform that unifies design, execution, and operations for cloud infrastructure.

## Positioning Statement

> For platform engineers at growing SaaS companies, CloudBuilder is the visual infrastructure platform that turns architecture diagrams into running cloud infrastructure, unlike manual Terraform workflows or disconnected design tools, because it unifies design, code generation, provisioning, and observability in a single visual environment.

## Positioning Matrix

### For Platform Engineers
> "Design infrastructure visually. Generate Terraform. Deploy in minutes. Monitor automatically."

### For DevOps Engineers
> "One canvas for all your cloud resources. Design, provision, and observe without switching tools."

### For CTOs
> "Infrastructure your whole team can understand. Visual designs that become production infrastructure."

## Competitive Positioning

### vs. Terraform/Pulumi (IaC tools)
- **They:** Write code to manage infrastructure
- **We:** Design visually, generate code automatically
- **Differentiator:** Visual interface + automatic code generation + observability

### vs. Miro/Lucidchart (Design tools)
- **They:** Design diagrams that don't connect to execution
- **We:** Design diagrams that become real infrastructure
- **Differentiator:** Designs are executable, not just documentation

### vs. AWS/GCP Console (Cloud consoles)
- **They:** Provider-specific, imperative, complex
- **We:** Multi-provider, visual, simplified
- **Differentiator:** Cross-cloud abstraction + visual design

### vs. Backstage/Port (Developer portals)
- **They:** Catalog of existing infrastructure
- **We:** Design and create new infrastructure
- **Differentiator:** Creation + execution, not just discovery

### vs. Humanitec/Qovery (Platform engineering)
- **They:** Abstraction layers over cloud providers
- **We:** Visual design → code → execution
- **Differentiator:** Visual interface + code transparency

## Key Differentiators

1. **Visual → Executable** — The only tool where a visual design becomes running infrastructure
2. **Multi-cloud from day one** — Design works across AWS, GCP, Azure, K8s
3. **Code transparency** — See and edit the generated Terraform at any point
4. **Built-in observability** — Provisioned resources auto-connect to monitoring
5. **AI-enhanced** — Natural language design, intelligent recommendations
6. **Open source** — Trust through transparency, community-driven

## What We're NOT

- **Not a CI/CD tool** — We don't deploy applications
- **Not a cloud console replacement** — We don't manage individual resources
- **Not a generic design tool** — We're infrastructure-specific
- **Not a chatbot** — AI is a capability, not the product
- **Not enterprise-only** — We serve individual developers too
