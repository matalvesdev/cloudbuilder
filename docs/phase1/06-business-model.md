# CloudBuilder — Business Model

## Business Model Canvas

| Segment | Detail |
|---------|--------|
| **Value Proposition** | Visual infrastructure design → code generation → provisioning → monitoring → cost optimization → AI operations in one open-source platform |
| **Customer Segments** | Platform engineering teams, DevOps/SRE teams, Cloud architects, FinOps practitioners, Engineering leaders |
| **Channels** | GitHub (open source), Website (cloudbuilder.dev), Documentation, Community forums, Enterprise sales, Cloud marketplaces (AWS, Azure, GCP) |
| **Customer Relationships** | Open source community (Discord, GitHub Discussions), Enterprise support (SLAs), Professional services, Training and certification |
| **Revenue Streams** | Enterprise license (SSO, RBAC, Audit), Cloud-hosted version, AI credits (premium analysis), Professional services, Marketplace integrations |
| **Key Resources** | Core engineering team, Open source community, Cloud provider partnerships, AI/ML models, Reference architectures |
| **Key Activities** | Platform development, Community management, Content creation, Enterprise sales, Cloud provider certifications |
| **Key Partnerships** | Cloud providers (AWS, Azure, GCP), HashiCorp (Terraform ecosystem), CNCF (OpenTofu, K8s), OpenTelemetry project, Linux Foundation |
| **Cost Structure** | Engineering salaries, Cloud infrastructure (CI/build), Community programs, Marketing, Sales |
| **Competitive Advantage** | Open source + visual + full lifecycle + AI-native = unique combined value proposition |
