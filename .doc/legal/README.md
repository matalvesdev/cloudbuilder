# CloudBuilder — Jurídico & Compliance

## LGPD (Lei Geral de Proteção de Dados)

### Dados Coletados
- **Dados de identificação**: Nome, email
- **Dados de uso**: Logs de acesso, ações no sistema
- **Dados de infraestrutura**: Designs, configs, credenciais (encriptadas)

### Base Legal
- **Consentimento**: Registro explícito
- **Execução de contrato**: Uso do serviço
- **Legítimo interesse**: Analytics agregados

### Direitos do Titular
- Acesso aos dados
- Correção de dados
- Exclusão de dados
- Portabilidade
- Revogação do consentimento

### Segurança dos Dados
- Encryption at rest (AES-256-GCM)
- Encryption in transit (TLS 1.3)
- Multi-tenant isolation
- Access logging completo

## Termos de Uso

### Aceitação
Ao usar o CloudBuilder, você concorda com nossos Termos de Uso.

### Uso Aceitável
- Não usar para atividades ilegais
- Não tentar acessar dados de outros tenants
- Não sobrecarregar o sistema deliberadamente

### Disponibilidade
- SLA: 99.9% uptime (Enterprise)
- Manutenção programada: com 48h de antecedência

### Propriedade Intelectual
- Código-fonte: Propriedade da CloudBuilder
- Dados do usuário: Propriedade do usuário
- Designs criados: Propriedade do usuário

## Privacidade

- Não vendemos dados de terceiros
- Não compartilhamos dados pessoais com terceiros
- Analytics são agregados e anônimos
- Cookies apenas para autenticação
