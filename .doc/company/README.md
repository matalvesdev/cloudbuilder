# CloudBuilder — Sobre a Empresa

## O que é a CloudBuilder

A CloudBuilder é uma plataforma de **Platform Engineering** que permite a empresas:

- **Projetar** infraestrutura visualmente (canvas drag-and-drop com providers AWS, Azure, GCP, K8s)
- **Provisionar** automaticamente (geração de Terraform/OpenTofu a partir do design visual)
- **Monitorar** custos e operações (FinOps, observabilidade, drift detection)
- **Gerenciar** segurança e compliance (RBAC, multi-tenant, auditoria)

## Problema que Resolvemos

As empresas hoje enfrentam:

1. **Ferramentas fragmentadas** — Terraform em um terminal, custos em outro dashboard, monitoramento em terceiro lugar
2. **Barreira de entrada para DevOps** — Equipes não-técnicas não conseguem visualizar ou provisionar infraestrutura
3. **Custo opaco** — Sem visibilidade real de quanto cada recurso gasta, sem otimização automática
4. **Drift não detectado** — Infraestrutura sai do estado desejado sem alerta
5. **Governança fraca** — Sem aprovações, sem auditoria, sem compliance automatizado

## Nosso Produto

A CloudBuilder é um **SaaS** com as seguintes capabilities principais:

| Módulo         | O que faz                                              |
| -------------- | ------------------------------------------------------ |
| **Design**     | Canvas visual para projetar infraestrutura             |
| **Provision**  | Geração automática de Terraform + deploy               |
| **Observe**    | Health checks, alertas, Service Map, Scorecards        |
| **Cost**       | Dashboard FinOps, anomaly detection, what-if analysis  |
| **AIOps**      | Assistente IA para incidentes e remediation            |
| **Platform**   | Catálogo de templates, marketplace, partner integration|
| **IAM**        | RBAC completo, multi-tenant, SSO, MFA                  |
| **Audit**      | Trilha de auditoria completa para compliance            |

## Público-Alvo

- **Arquitetos de Solução** que querem tudo em um lugar só
- **Equipes DevOps/SRE** que precisam de visibilidade e automação
- **FinOps/Financeiro** que querem controlar custos de cloud
- **CTOs/Heads de Platform** que querem self-service para devs
- **Empresas em crescimento** que precisam de governança sem burocracia
