# Missão, Visão e Valores

## Missão

**Democratizar o Platform Engineering** — tornar a gestão de infraestrutura, custos e operações acessível para qualquer equipe, de qualquer tamanho, em qualquer lugar da América Latina e além.

## Visão

Ser a **plataforma padrão** para empresas que querem gerenciar infraestrutura cloud de forma visual, inteligente e segura. Em 5 anos, a CloudBuilder será o "GitHub da infraestrutura" — onde times projetam, provisionam, monitoram e otimizam tudo em um só lugar.

## Valores

### 1. 🎯 Simplicidade Radical
- Complexidade é o inimigo. Se não é simples de usar, não está pronto.
- Preferimos uma feature bem-feita a dez features medianas.

### 2. 🔒 Segurança por Padrão
- Multi-tenant isolation, RBAC, audit log — não são opt-in, são o padrão.
- Cada decisão técnica passa pelo filtro: "isso é seguro por padrão?"

### 3. 📊 Dados Acima de Opiniões
- FinOps não é achismo. Cada custo é rastreável, cada decisão tem métrica.
- Anomaly detection, budget alerts, what-if analysis — tudo baseado em dados reais.

### 4. 🚀 Automação com Humano no Loop
- Automatizamos o repetitivo, mas mantemos humano nas decisões críticas.
- Deploy automatizado, mas com aprovação. IA sugere, humano decide.

### 5. 🌍 Open-Source Friendly
- Construímos sobre stack open-source (React, Java, Go, PostgreSQL, Terraform).
- Quando possível, contribuímos de volta para a comunidade.

### 6. 🔄 Evolução Contínua
- O produto nunca está "pronto". Sempre há algo para melhorar.
- Aprendemos com cada bug, cada feedback, cada deploy.
