# CloudBuilder — People & Culture

## Cultura

### Valores em Prática
1. **Ownership** — Cada pessoa é dona do seu resultado
2. **Transparência** — Decisões abertas, contexto compartilhado
3. **Velocidade** — Preferimos iteration speed over perfection
4. **Qualidade** — Não sacrificamos qualidade por velocidade
5. **Aprendizado** — Erros são oportunidades, não punições

## Estrutura Atual

### Equipe Fundadora
- **CEO / Co-founder**: Visão, estratégia, business
- **CTO / Co-founder**: Tech, arquitetura, engenharia

### Próximas Contratações (Q3-Q4 2026)
- Senior Backend Engineer (Java/Spring)
- Senior Frontend Engineer (React/TypeScript)
- DevOps/SRE Engineer
- Product Designer (UX/UI)

## Processos

### Comunicação
- **Sincrona**: Daily standup (15min), weekly sync (1h)
- **Assíncrona**: GitHub issues/PRs, Slack/discord

### Decisões
- **Técnicas**: ADR (Architecture Decision Records)
- **Produto**: RFC (Request for Comments)
- **Business**: OKR quarterly review

### Code Review
- Todo PR precisa de 1 approval
- CI deve passar antes de merge
- Branch protection no `main`

## Benefícios (planejado)

- Flexibilidade de horário
- Home office
- Learning budget
- Health insurance
- Equity para early employees

## Processo Seletivo

1. **Apply**: Formulário + CV
2. **Tech Screen**: 30min call técnica
3. **Coding Challenge**: Exercício prático (4h max)
4. **Culture Fit**: 30min com founding team
5. **Offer**: Proposta e negociação
