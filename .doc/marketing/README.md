# CloudBuilder — Marketing

## Posicionamento

**CloudBuilder** é a plataforma de Platform Engineering que unifica design, provisionamento, observabilidade e FinOps em uma única interface visual.

### Tagline
> "Projete, provisione e monitore sua infraestrutura — tudo em um lugar."

### Diferencial
- **Visual-first**: Canvas drag-and-drop (não precisa saber Terraform para começar)
- **FinOps integrado**: Custo visível desde o design, não só no deploy
- **Multi-provider**: AWS, Azure, GCP, K8s em uma única plataforma
- **Self-service**: Devs provisionam sem pedir para infra
- **Governance built-in**: RBAC, aprovações, audit trail sem setup extra

## Público-Alvo

### ICP (Ideal Customer Profile)
- Empresas com 50-500 funcionários
- Equipes de engenharia com 5-50 devs
- Infraestrutura cloud (AWS/Azure/GCP)
- Crescimento rápido, precisam de governança

### Canais
1. **Content Marketing**: Blog técnico, dev.to, medium
2. **Social**: LinkedIn, Twitter/X, YouTube
3. **Community**: GitHub open-source, Discord
4. **Partnerships**: Consultorias, cloud providers
5. **Events**: DevOps Days, AWS re:Invent, Google Cloud Next

## Concorrência

| Player        | Diferencial CloudBuilder              |
