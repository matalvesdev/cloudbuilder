## Twitter/X Threads

### Thread 1: O que é Platform Engineering
```
🧵 O que é Platform Engineering? (thread)

1/ Platform Engineering é a prática de construir uma plataforma interna que permite que devs provisionem infraestrutura de forma self-service.

2/ Diferente de DevOps tradicional (onde cada dev faz tudo), Platform Engineering cria uma camada de abstração.

3/ O resultado? Devs provisionam ambientes em MINUTOS, não em dias.

4/ Ferramentas como o CloudBuilder tornam isso realidade com canvas visual + Terraform automático.

5/ Quer saber mais? cloudbuilder.io
```

### Thread 2: FinOps
```
🧵 5 dicas de FinOps para controlar custos cloud (thread)

1/ Visibilidade: Você não pode otimizar o que não pode ver. Comece com um dashboard de custos.

2/ Budget Alerts: Configure alertas em 80% e 100% do orçamento. Nunca mais seja surpreendido.

3/ Anomaly Detection: Identifique custos fora do padrão automaticamente.

4/ What-If Analysis: Estime custos ANTES de provisionar. O CloudBuilder faz isso automaticamente.

5/ Right-Sizing: Ajuste o tamanho dos recursos para a demanda real. Não pague por capacidade ociosa.
```

### Thread 3: Terraform Visual
```
🧵 Terraform sem código? É possível! (thread)

1/ O CloudBuilder permite projetar infraestrutura visualmente e gerar Terraform automaticamente.

2/ Arraste recursos (AWS, Azure, GCP, K8s) para o canvas.

3/ Conecte-os arrastando de um para outro.

4/ Configure propriedades no painel direito.

5/ Valide o design (detecta erros automaticamente).

6/ Gere Terraform (5 arquivos HCL) com um clique.

7/ Deploy via pipeline com aprovação.

8/ Tudo isso sem escrever uma linha de Terraform.
```
