# CloudBuilder Discord — Quick Start

## 🚀 Setup em 5 minutos

### 1. Criar Servidor
```
Discord → + → Criar servidor → "CloudBuilder"
```

### 2. Criar Categorias (arraste para cima)
```
📢 ANÚNCIOS
💬 GERAL
🛠️ TÉCNICO
🎯 PLATAFORMA
💰 FINOPS
📚 RECURSOS
🔒 ADMIN
```

### 3. Criar Canais Rápidos
```
#anúncios (somente staff)
#geral (todos)
#ajuda (todos)
#cloudbuilder (todos)
#finops (todos)
```

### 4. Criar Roles
```
@Staff (amarelo, admin)
@Moderador (azul, mod)
@Membro (cinza, read)
```

### 5. Criar Link
```
Servidor → Convites → Criar → Copiar
```

| Canal | Finalidade |
